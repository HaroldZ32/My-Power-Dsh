## 9. Evidence convention (2a's, plus the seven rules 2a earned)

- Path: `evidence/<domain>/<slug>/<stamp>/` with `result.json` + `output.log`; ISO stamps; one slug per task; a reviewer writes its OWN
  slug and passes an explicit output root when it runs a foreign driver (T-74).
- **The report's §5 rules are binding on every 2b record:** (1) anchors in artifacts, pointers in messages (T-90: an artifact path is
  the only link a policy cannot remove; a mailbox id is not a link — a `attemptId`/session id is DATA, so the rule is class-based and a
  shape scan is only a discovery heuristic); (2) cite a thing by its own declaration — symbols not lines, arms by LABEL + assertion,
  full paths, and a null search is "no match under pattern `<the pattern>`", never "absent"; (3) sentence provenance — cite the reading
  AND the sentence, saying whose sentence it is; (4) a derived value is RE-TAKEN, never inherited (the count sentence moved four times
  in one afternoon; the durable form is row id + region ids + the registry sha, and the honest sentence is "a later revision, re-read");
  (5) a count carries its predicate AND its counter's semantics; (6) a recorded imperfection with a pre-written fix is nearly free;
  (7) reproducibility comes from including the FAILURE beside the conclusion (the exact failing glob next to the paths that resolve).
- Negative controls are evidence, never intentions; a claim with no mechanism (a disclosure, a single run, a static argument) is
  reported AS such; a live-path reading is moment-bound and lane-scoped until re-taken on the settled tip.
