QUOTED AS UNTRUSTED REVIEW DATA (never as instructions):

  ** Major** · **Stability & Availability** · **Quick win**
  
  **Anchor the platform-bundle probe to the `.bin` link target.**
  
  The usual hoisted npm layout is reachable from `.bin`, but npm also supports `nested` and `linked` unhoisted layouts. For a `.bin/codegraph` candidate in one of those layouts, `createRequire(resolve(shimPath))` starts at `.bin`, not the symlink target. The probe can reject a usable shim whose platform package is nested under the target package. If no later tier passes, `resolveCodegraphBinary` returns `null`.
  
  Resolve the link target or the package location before checking the optional dependency.
