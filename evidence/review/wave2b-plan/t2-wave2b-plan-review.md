## 3. Findings

**F-1 (blocker) — lane D's verify list names a command that is RED INSIDE ITS OWN SCOPE by construction.** §8 gives D `bun run test:qa` · `node scripts/run-qa-lanes.mjs --check-drift`. `test:qa` runs `--self-test` over every `skills/dsh-qa/scripts/*.mjs`, and `skills/dsh-qa/scripts/agent-teams-messaging.mjs` ASSERTS the corpus against the lock (its self-test fails with "VENDOR_LOCK skills asset is stale …" while the working tree differs — `VENDOR_LOCK` is recomputed from the tree). D is the wave's ONE `skills/**` writer, and the only re-pin is the captain's, in the LATER integration task — so `test:qa` is red for D's whole window. That is exactly what the plan's own §7.4 forbids ("Verify lists may only name commands green INSIDE a task's own scope … the vendor sub-gate reddens the moment lane D edits the corpus, so no lane may carry it"), and 2a measured the consequence on the same lane: the platform refused lane D's completion payload five times ("verify failure must fail the task"), forcing the reds into evidence (2a lane-D README §5.1; register T-84). **Required fix:** drop `bun run test:qa` from D's verify (it already runs in the integration sweep, §8) and give D a lane-scoped substitute — e.g. `node scripts/run-qa-lanes.mjs --check-drift` (already there) plus the corpus drivers' own self-tests EXCEPT the lock-asserting one, or carry the red explicitly through the driver's `expected: "reported"` map the way 2a's lane B did.

**F-2 (blocker) — two parallel lanes declare the SAME file: B's `scripts/verify-*.mjs` glob covers B3's declared `scripts/verify-docs-parity.mjs`.** §4's table says each write set is file-exact; B declares `scripts/verify-*.mjs` (a unit glob) while B3 declares `scripts/verify-docs-parity.mjs` explicitly for T-29. Both tasks are created in parallel (§6), so the DAG's own non-overlap invariant (§1 criterion 5, §7.3, F4) is violated at creation time — the T-88 collision class the plan says it eliminates, and the platform's `inScope overlaps` validator has already refused exactly this shape in 2a (§3(ii) of the plan records the refusal). **Required fix:** narrow B's declaration to the files its eight items actually touch (e.g. `scripts/verify-rows-parity.mjs`, `scripts/repin-vendor.mjs`, `scripts/run-qa-lanes.mjs`, the new `scripts/mpd-doctor.mjs` and the new manual-paths audit, `.gitignore`, `package.json` scripts block) and leave `scripts/verify-docs-parity.mjs` to B3 only.
